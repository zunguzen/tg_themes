# 霧 Kiri — Zen themes for Telegram iOS and Android

Six quiet themes inspired by Japanese landscapes: fog, ink, forest, moon and snow.
They come in three dark/light pairs, so you can use them with Auto-Night Mode.

## Installation

Open the link of a theme below on your phone and tap **Apply**. The same link works on iPhone and on Android. If a link does not work, install from a file:

- iPhone: use the `.tgios-theme` file. Android: use the `.attheme` file with the same name (for example `washi.attheme`).

1. Send the theme file to yourself (for example, in Saved Messages).
2. Tap the file and choose **Apply**.
3. To switch automatically, apply the light theme first. Then go to Auto-Night Mode (iPhone: **Settings › Appearance**, Android: **Settings › Chat Settings**), choose **Automatic** or **Scheduled**, and pick the dark theme from the same pair.

## 墨 Sumi · Ink

Ink wash and the paper it is painted on. Accent: vermilion, like a hanko seal.

### 墨夜 Sumi-yo — Dark
*すみよ · ink night* · `sumi-yo.tgios-theme` 
https://t.me/addtheme/sumiyo

Mountains at night painted in sumi ink. Near-black charcoal with warm off-white text. The only color is a muted vermilion.

### 和紙 Washi — Light
*わし · Japanese paper* · `washi.tgios-theme` 
https://t.me/addtheme/washi

Handmade mulberry paper. Warm ivory background, ink-black text and outgoing bubbles, with the same vermilion seal accent.

## 霧 Kiri · Mist

Fog moving through forest and over water. Accent: moss green.

### 苔霧 Koke-giri — Dark
*こけぎり · moss fog* · `koke-giri.tgios-theme` 
https://t.me/addtheme/kokegiri

Deep forest after rain. Green-tinted blacks, misty grey-green text, soft moss bubbles.

### 朝霧 Asagiri — Light
*あさぎり · morning mist* · `asagiri.tgios-theme` 
https://t.me/addtheme/asagiri

Dawn mist over a still lake. Cool grey-green whites, pale jade outgoing bubbles, deep pine accent.

## 月 Tsuki · Moon & Snow

Moonlight and snow in a mountain temple. Accent: pale gold.

### 杉月 Sugi-tsuki — Dark
*すぎつき · cedar moon* · `sugi-tsuki.tgios-theme` 
https://t.me/addtheme/sugitsuki

Moonlight between tall cedars. Blue-black night, cool silver text, pale moon-gold accent.

### 雪寺 Yuki-dera — Light
*ゆきでら · snow temple* · `yuki-dera.tgios-theme` 
https://t.me/addtheme/yukidera

A temple under fresh snow. Clean snow-white with cool grey, warm sand bubbles like old temple wood, bronze accent.

## Notes

- Wallpapers are plain solid colors. Calm, low-contrast photos (fog, snow, empty sky) also work well.
- Text and background contrast meets WCAG AA readability levels.
- Asagiri and Washi are real Japanese words. The other four names are poetic compounds.
