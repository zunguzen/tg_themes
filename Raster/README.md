# Raster — Telegram iOS themes

A pair of minimal Telegram themes after the Swiss International Typographic Style: a white or black background, ink-colored text, one red accent and strong dividers. No tints, no gradients, no decoration.

## Files

- `raster-weiss.tgios-theme`: light theme (based on Day)
https://t.me/addtheme/rasterWeiss
- `raster-schwarz.tgios-theme`: dark theme (based on Night)
https://t.me/addtheme/rasterSchwarz

## Palette

**Weiss (light)**
- Background `#FFFFFF`, grouped lists `#F2F2F2`
- Text `#111111`, secondary text `#5E5E5E`
- Accent `#EC3013`
- Sent bubbles `#111111` with light text; received bubbles `#EFEFEF`
- Dividers: `#111111` under the bars, `#D4D4D4` between list rows

**Schwarz (dark)**
- Background `#0A0A0A`, grouped list items `#161616`
- Text `#F2F2F2`, secondary text `#909090`
- Accent `#FF3B1F`
- Sent bubbles `#333333`; received bubbles `#1C1C1C`
- Dividers: `#F2F2F2` under the bars, `#2A2A2A` between list rows

## Principles

- One accent. Buttons, links, unread badges, the selected tab and destructive actions all share the red.
- Strong dividers. The lines under the navigation bar and above the tab bar and message field are full-strength ink.
- Neutral grays only. Everything outside the red is pure grayscale.
- No green. Online dots, positive switches and secret-chat titles use ink instead, so secret chats don't stand out from regular ones.

## Install

**Android:** send the `.attheme` file (`raster-weiss.attheme` or `raster-schwarz.attheme`) to any chat, tap it in Telegram and choose Apply. These files are converted from the iOS themes, so the look is very close but not identical.

**iPhone:** send the `.tgios-theme` file to any chat (Saved Messages works), tap it in Telegram for iOS, then tap Apply.

Telegram fixes the bubble and avatar shapes, so these themes change colors only.
